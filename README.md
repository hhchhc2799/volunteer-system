# 开发组任务登记及志愿时长分配系统

## 项目简介

这是一个用于开发组任务登记和志愿时长分配的网页系统。

目前项目处于开发阶段，主要用于学习 HTML、CSS 和 JavaScript，并逐步实现任务管理和志愿时长统计功能。

## 当前功能

### 人员管理

- 添加组员
- 删除组员
- 查看组员列表
- 查看当前志愿时长

### 任务管理

- 创建任务
- 选择任务参与人员
- 记录任务时间
- 记录任务对应的志愿时长
- 查看任务列表
- 删除任务
